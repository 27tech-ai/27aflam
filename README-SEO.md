# 27AFLAM 2.0

This folder is a separate upgraded copy of the original 27AFLAM site.

## Included improvements

- SEO title, description, keywords, canonical URL and robots metadata.
- Open Graph and Twitter metadata for better sharing previews.
- Schema.org structured data for `WebSite`, `Organization` and FAQ.
- `robots.txt`, `sitemap.xml` and `manifest.webmanifest`.
- Dynamic watch-page titles and descriptions after TMDB details load.
- Search URL support with `?q=movie-name`.
- Better image alt text, focus states and accessibility labels.
- Anime adult-content filtering and sensitive anime cover blur remains active.
- Apache `.htaccess` cache, compression and security headers.

## Before publishing

Replace `https://27aflam.com/` in these files if your real domain is different:

- `index.html`
- `robots.txt`
- `sitemap.xml`

After uploading, submit `https://your-domain.com/sitemap.xml` in Google Search Console.
